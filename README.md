# ai_python

本项目用于学习 Python 基础和 TensorFlow 基础，包含常用示例和 Jupyter Notebook 支持。

## 目录结构
```
notebooks/        # Jupyter Notebook 示例
src/              # Python 脚本示例
README.md         # 项目说明
requirements.txt  # 依赖列表
```

## 环境安装
1. 安装 Python 3.8+（推荐 Anaconda）
2. 安装依赖：
   ```powershell
   pip install -r requirements.txt
   ```
3. 启动 Jupyter Notebook：
   ```powershell
   jupyter notebook
   ```

## 示例说明
- notebooks/ 目录下包含 TensorFlow 基础、数据处理、模型训练等示例。
- src/ 目录下包含 Python 基础语法、函数、类、文件操作等脚本。

---

如需扩展功能，请在 notebooks 或 src 目录下添加新文件。
